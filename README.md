# TypeScript OOP

A hands-on TypeScript repository focused on learning and practicing Object-Oriented Programming (OOP) concepts, utility classes, and core TypeScript features.

## 📌 About This Repository

This repository contains my TypeScript learning journey, where I practice different TypeScript concepts through practical code examples and small exercises.

The main goal is to strengthen my understanding of TypeScript and Object-Oriented Programming principles.

## 🚀 Topics Covered

- TypeScript Fundamentals
- Classes and Objects
- Constructors
- Access Modifiers (`public`, `private`, `protected`)
- Encapsulation
- Inheritance
- Polymorphism
- Getters and Setters
- Static Properties and Methods
- Utility Classes
- TypeScript Types and Interfaces

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Mezba-Morsalin/typescript-oop.git
```

**2. Navigate to the project directory**

```bash
cd typescript-oop
```

**3. Install TypeScript (if not already installed)**

```bash
npm install -g typescript
```

**4. Compile TypeScript files**

```bash
tsc
```
